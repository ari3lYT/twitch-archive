# Настройка

| Переменная | По умолчанию | Применение |
| --- | --- | --- |
| `CHANNEL` | `example_channel` | Загрузчик и контроллер; задайте явно |
| `ARCHIVE_ROOT` | `/archive` (загрузчик), `./archive` (контроллер) | Хранилище записей |
| `STATE_ROOT` | `/state` (загрузчик), `./state` (контроллер) | Очередь, управление и телеметрия |
| `DOWNLOAD_START` / `DOWNLOAD_END` | `06:30` / `23:30` | Общий ежедневный интервал и ETA |
| `ARCHIVE_TIMEZONE` | `Europe/Moscow` | Часовой пояс интервала |
| `MIN_FREE_BYTES` | 100 ГиБ | Резерв свободного места загрузчика |
| `PANEL_BASE` | `./panel` | Каталог контроллера; сокет внутри: `control/agent.sock` |
| `CONTROL_UID` / `CONTROL_GID` | Текущие UID/GID | Разрешённый клиент панели и владелец файлов |
| `DOCKER_BINARY` | `docker` | Исполняемый файл контроллера |
| `ARCHIVE_CONTAINER` | `twitch-archive` | Фиксированное имя контейнера загрузчика |
| `PANEL_STATE` | `/panel-state` | Каталог авторизации и проверок панели |
| `MEDIA_ROOT` | `/archive` | Доступ панели к записям только для чтения |
| `CONTROL_SOCKET` | `/control/agent.sock` | Подключение панели к контроллеру |
| `PUBLIC_ORIGIN` | `https://archive.example.com` | Точный TLS origin для CSRF |
| `PANEL_HOST` / `PANEL_PORT` | `127.0.0.1` / `8925` | Адрес и порт HTTP |

`state/settings.json` содержит проверяемые параметры работы: опрос, задержку стабилизации, тайм-аут сокета, резерв места, интервалы повторов, ограничение скорости и число исполнителей. Пути загрузчика и контроллера должны указывать на одно хранилище, даже если точки монтирования контейнеров называются по-разному.

Рабочее состояние содержит метаданные просмотров, сообщения записи и данные авторизации. Сохраняйте весь рабочий каталог приватным. Реальные архивы, учётные записи, настройки и секреты в репозиторий не включены.
