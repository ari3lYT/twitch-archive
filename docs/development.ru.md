# Разработка

Установите `requirements.txt`. Выполните `python tools/check.py` из корня репозитория: команда проверяет совпадение копий расписания и запускает два набора тестов в отдельных процессах Python. Это необходимо, поскольку оба каталога сервисов используют локальные имена модулей, например `transfer_stats`.

| Модуль | Ответственность |
| --- | --- |
| `archiver/archive.py` | Поиск записей, очередь, буферизация сегментов и надёжная фиксация |
| `archiver/chat_archive.py` | Сохранение позиции чата записи и экспорт |
| `archiver/archive_insights.py` | Шкала событий и сводки активности по сообщениям |
| `archiver/transfer_stats.py` | Постоянная телеметрия передачи и ETA по расписанию |
| `dashboard/server.py` | HTTP API с авторизацией, статический интерфейс и ограниченное чтение медиа |
| `dashboard/agent.py` | Проверка Unix-клиента и разрешённые операции управления |

Используйте временные каталоги в тестах. Подменяйте ответы Twitch и подпроцессы. В CI не запускайте замеры производительности или загрузку в реальный архив. Формат архивного видео — транспортный поток (`.ts`); FFmpeg/ffprobe являются внешними инструментами и не входят в исходники.
