# Twitch Archive

Архиватор VOD с возобновлением по фрагментам, выгрузкой доступного replay-чата и закрытой панелью.
Начни с README и `docs/deployment.md`. Укажи свой канал, каталоги и origin панели.

По умолчанию загрузки разрешены 06:30–23:30 МСК. Ночью NAS не пробуждается; ETA учитывает перерыв.
Публичный репозиторий содержит код и демонстрационные данные, без личного видеоархива и переписок.
