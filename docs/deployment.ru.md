# Развёртывание панели

1. Запустите загрузчик в контейнере с фиксированным именем `ARCHIVE_CONTAINER`, подключив постоянные каталоги архива и состояния. Dockerfile находится в `archiver/`. Аргументы сборки UID/GID должны соответствовать владельцу хранилища.
2. Создайте приватный каталог состояния панели и выполните `python tools/init_auth.py /path/to/panel-state`. Пароль вводится без отображения, хешируется со случайной солью и записывается с правами 0600.
3. Настройте пути контроллера (`PANEL_BASE`, `STATE_ROOT`, `ARCHIVE_ROOT`) и UID разрешённого клиента. Запустите `python dashboard/agent.py`, предоставив только нужный доступ к Docker и хранилищу.
4. Задайте `PANEL_STATE`, `MEDIA_ROOT`, `CONTROL_SOCKET` и точный `PUBLIC_ORIGIN` панели. Запустите `python dashboard/server.py` от непривилегированного пользователя.
5. Направьте `/twitch/` через обратный TLS-прокси на локальный HTTP-сервис. Cookie сессии имеет флаг Secure и не работает через обычный HTTP. Не открывайте клиентам сокеты агента или Docker.

Включённый контроллер рассчитан на Docker. Для загрузчика вне контейнера нужен адаптер контроллера; подстановка произвольной команды оболочки не обеспечивает такую поддержку. Репозиторий не меняет график питания NAS, системные сервисы или правила межсетевого экрана.

Для локальной демонстрации и скриншотов выполните `python tools/demo.py`: он запускает настоящую панель с искусственными записями и тестовым контроллером только для чтения. Демонстрационные данные входа не действуют в развёрнутой установке.
