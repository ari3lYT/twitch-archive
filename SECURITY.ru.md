# Сообщения об уязвимостях

Используйте приватные сообщения об уязвимостях GitHub, если они включены для репозитория. Иначе создайте минимальную задачу с просьбой предоставить приватный канал связи, без описания эксплуатации и секретов. Не публикуйте действующие токены, приватные файлы, экспорты сообщений, базы игроков или адреса рабочих сервисов.

Если секрет случайно опубликован, замените его. Удаление из последнего коммита не удаляет его из истории Git, форков, кэшей или скачанных архивов.
