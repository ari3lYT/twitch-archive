    Движок параллельного скачивания

    До 256 фрагментов одновременно с общим лимитом буфера. Единая запись по порядку и контрольная точка после каждого фрагмента.

    PARALLEL / DURABLE

    Замер ещё не выполнялся.

    Сравнение 1 / 4 / 8 / 16 / 32 / 64 / 128 / 256 потоков и повтор лучших режимов. Тест занимает несколько минут, очередь продолжится сама.

    Архиватор

    Сохранённые записи и позиции загрузок останутся на месте. Перезапускается только наш архиватор.
